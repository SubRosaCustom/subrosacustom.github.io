What is SR:C?

SRC is a client-side mod for Sub Rosa. You launch it through SRC Launcher. After that, it runs inside the game with the normal game files.

SR:C does NOT replace the game files, add files or whatsoever. You should only download the SRC Launcher through our links and launch it from there.

SR:C does NOT require a replacement of the original game files, do NOT trust people who give download links, only OFFICIAL sources are here.

SRC is not a decompilation, replacement or anything else, its just a mod. It does not replace Sub Rosa. You still start Sub Rosa, and you still play on Sub Rosa servers. SRC only adds things the normal game cannot show.

What does SR:C offer?

SR:C provides commonly used game patches the community have made over the years and adds more on top of it.

  • Tire marks
  • Blood and glass mod (their particles stay for one minute) and persistent bullet marks
  • Clouds
  • The 37 desert landscape texture
  • Adjustable building view distance
  • Building textures fix
  • Proper minimap
  • Sky and water toggles
  • Bit crushed voice chat quality, for people who want old voice quality back
  • Mag fix (magazine alignment)
  • An FPS slider for the game and the menu
  • Shadows toggle, rubble toggle, and reflections toggle you can turn off for more frames
  • Sync bar

You turn each of these on or off yourself. They are your settings, not the server's.

SR:C makes it WAY EASIER to play on servers with custom content

  • map syncing
  • asset syncing

A server that uses SRC can give you:

  • custom items, with their own models, icons, sounds and textures
  • custom vehicles, vehicle types, vehicle sounds
  • custom character models, neckties, necklaces
  • custom sounds and textures
  • map markers (blips), player labels, and other things drawn on your screen
  • client-side Lua scripting

Every server chooses its own. Two servers can look completely different.

Why a server did not let you in

The custom content has to be on your computer for you to see it. A player without SR:C would see broken or missing objects. So a server that uses SRC can turn away players who do not have it. That is the message you saw.

Server owners with SR:C integration enabled have to ability to choose whether to kick non SR:C players or not.

Install SRC and you can join.

What happens when you join a server

The server sends you the files it uses. Map, vehicles, items, scripts, textures, sounds and so on. This happens by itself, each time you connect.

You do not download files for each server. You do not install anything by hand. You do not keep anything up to date. When you go to a different server, it sends you its own files instead.

What SRC does not do

  • It does not change servers that do not use SR:C. Those still work the same, and you can still play on them.
  • It does not change your Sub Rosa files. It loads into the game while the game starts.

The parts

You only need the launcher. The rest is here so you know what runs on your computer:

  • SRCLauncher is what you download on this page. It installs SRC, keeps it up to date, and starts Sub Rosa with it.
  • The client is the mod. The launcher loads it into the game. It draws the custom content and talks to the server.
  • The server parts are installed by the people who run servers. You never install these.

Setup

Install and open SRCLauncher. In Settings, check that it found your Sub Rosa installation. If not, pick the folder yourself. Then press Launch SRC.

If the AppImage will not open:

chmod +x srclauncher_*.AppImage
