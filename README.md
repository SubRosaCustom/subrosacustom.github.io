## Install SRC

You need SRCLauncher to join this server. It installs SRC, keeps it updated, and starts Sub Rosa correctly.

## 1. Download SRC Launcher

Download links... Select a download link for your operating system and install it.

On Linux, if you're not able to launch the AppImage, try changing its permissions.
```bash
chmod +x srclauncher_*.AppImage
```

## 2. Open SRC Launcher

After installation open SRC Launcher, in the settings check if your Sub Rosa installation was correctly found, if not change it to where your Sub Rosa installation resides in your computer.

## 3. Launch SRC

Press Launch SRC and Sub Rosa should automatically start with SRC.
